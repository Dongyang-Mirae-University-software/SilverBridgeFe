## 결정 (사용자 승인, 2026-10-30)
1. 시각이 지났는데 체크하지 않은 시간대: 탭 "체크 안 했어요", 패널 "체크되지 않은 약" - 안 드셨다고 단정하지 않는다. 오늘 목록(`doseDate`가 KST 오늘)일 때만 표시
2. 체크한 뒤 그 시간대에 머문다
3. 복용 단위는 "1정·반 알" 유지
4. 되돌리기 버튼 문구는 "잘못 눌렀어요"
5. 쓰이지 않는 피보호자 `WardMedicationCard.tsx`·`.module.css`는 그대로 둔다(범위 밖, 정리 후보)

## 변경 파일
- `src/app/(ward)/ward/medication/_components/WardMedicationContent.tsx` - 시간대 탭 + 고른 시간대 카드. 그룹 계산·체크·실패 처리는 그대로. 지금 시각은 `useKstNow`(1분 갱신, 병원 화면과 같은 훅)

- `WardMedicationContent.browser.test.tsx` - 새 구조에 맞춤 + 탭 전환·반 알·"체크 안 했어요"·약 6개 격자 테스트 추가

## 바뀌지 않는 것
- 체크·되돌리기만 있다(등록·수정·삭제 없음)
- 시간대 묶음 체크는 batch API로 전부 성공/전부 실패, 실패 시 안내 + 목록 다시 불러오기
- 연속 탭 잠금(`sendingRef`·`isChanging`), KST 자정 다시 불러오기
- "오늘 약 다 먹었어요", 오늘 늦게 등록한 약의 "내일부터 드세요", 로딩·빈 상태·불러오기 실패·새로고침
- 글자·버튼은 이전보다 작아지지 않았다(체크 버튼 76-84px, 되돌리기 64px, 약 글자 휴대폰 26px 이상). 탭 상태 글자는 19px 굵게(큰 글자 대비 기준)
