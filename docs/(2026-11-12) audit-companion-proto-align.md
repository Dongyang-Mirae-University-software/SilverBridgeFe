## 3. 이슈

### 🟠 H-1 폰 대답 영역이 깨진다 (#260 회귀)
- `.answer`를 `display: flex; flex-wrap: wrap`으로 바꾸고 폰에서 `flex-direction: column`만 더했다. 세로 방향에서는 `flex-basis: 100%`(글 입력 칸·안내 문구·카메라 묻기)가 **높이**로 계산되고, 줄바꿈이 켜져 있어 다음 항목이 **오른쪽 새 열**로 간다.
- 결과(폰 390, 글자 1.0배에서도): 글 입력 칸이 화면 몇 배 높이로 커지고, '말로 대답하기'·'대화 그만하기' 줄은 오른쪽 557px 밖. 글로 대답할 때·안내가 뜰 때 늘 생긴다.
- 수정안: 폰에서 `.answer { flex-wrap: nowrap }` + 100% 항목은 `flex-basis: auto`(또는 폰은 grid로). 화면 밖 여부를 재는 테스트를 함께(L-3).

### 🟡 M-1 폰 시작 화면 1.47배 가로 넘침
- 말벗 카드 머리의 오른쪽 여백 72px(테스트 표시 자리) + 큰 제목(40px×1.47) + 얼굴 88px로 최소 폭이 398px. 수정안: 폰에서 카드 안쪽 여백·제목 크기를 줄이고 테스트 표시는 머리 위 줄로.

### 🟢 L-1 '자세히' 버튼 폭 39px - `min-width: 44px`
### 🟢 L-2 죽은 CSS - 예전 시작 화면의 `.greeting`·`.testActions`, 폰 `.testStart { padding }`
### 🟢 L-3 테스트가 화면 밖 요소를 못 잡는다 - `toBeVisible`은 화면 밖도 '보임'. 폰 대답 줄은 `getBoundingClientRect().right <= innerWidth`로 확인
