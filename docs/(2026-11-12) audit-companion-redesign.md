## 4. 이슈

### 🟡 M-1 철회한 사람에게 동의 카드를 다시 묻는다
- BE는 철회 때 동의 행을 지워(`CompanionTranscriptService.setConsent` → `deleteByWardId`) `consentedAt`이 `null`로 돌아간다. FE는 `consentedAt == null` + 이 기기 '물어봄' 표시 없음이면 카드를 띄운다.
- 그래서 **환경설정에서 켰다 끈 사람**, **다른 기기에서 동의한 뒤 철회한 사람**은 다음 대화 때 카드를 다시 본다. 스스로 거절한 뒤 다시 묻는 것은 동의를 재촉하는 모양이 된다.
- 수정안: 환경설정 토글을 바꾸면 '물어봄' 표시도 남긴다(이 기기). 다른 기기는 수용(기기마다 한 번).

### 🟡 M-2 환경설정 토글 한 번에 보관 대화가 바로 지워진다
- 끄면 서버가 저장된 대화 글을 즉시 지운다(되돌릴 수 없음). 지금은 확인 없이 한 번 누르면 바로 PUT.
- 시니어 화면에서 잘못 누르기 쉽다. 수정안: 끌 때만 "끄면 지금까지 보관한 대화 내용이 바로 지워져요" 확인(끄기·그대로 두기 두 버튼).

### 🟢 L-1 최대 턴 수가 없을 때도 진행 점 8개를 그린다
- 타입 주석은 `maxTurns: null이면 표시하지 않는다`인데 점은 8개로 그린다(숫자 글만 숨김). 수정안: `null`이면 점도 숨긴다.

### 🟢 L-2 동의 상태를 받기 전에 시작하면 묻지 않고 시작한다
- 첫 대화에서 질문을 건너뛸 수 있다(다음 대화에서 묻는다). 수정안: 시작 때 동의 상태를 `fetchQuery`로 기다린 뒤 판단(실패하면 지금처럼 묻지 않음).

### 🟢 L-3 보관 일수 30을 화면에 고정
- 말벗 화면 저장 안내 "30일", 보호자 만료 안내 "보관 기간 30일"이 고정 글이다. 서버 값(`retentionDays`, 설정 `COMPANION_TRANSCRIPT_RETENTION_DAYS`)이 바뀌면 어긋난다. 수정안: 말벗 화면은 `retentionDays`, 보호자 만료 안내는 "보관 기간이 지나".

### 🟢 L-4 폰 판정 접기의 제목이 제목으로 읽히지 않는다
- `summary` 안의 `h2`는 버튼 역할에 묻혀 제목 탐색에 안 잡힌다. 테스트 전용 칸이라 영향은 작다.

### 🟢 L-5 보호자 7일·날짜 오류, 환경설정 불러오기 실패의 '다시 불러오기'가 44px보다 작다
- 글자 버튼(인라인)이라 높이가 글자 높이다. 수정안: `min-height: 44px`.

### 🟢 L-6 대화 보기 CSS에 토큰 밖 색 4개
- 기분 막대 연한 바탕(`#f6ead3`·`#f7ebcd`·`#e2edf4` 등). 기존 기분 칩 진한 색은 원래 있던 값. 수정안: `color-mix(in srgb, var(--mood) 15%, #fff)`.

### 🟢 L-7 대화 보기 주소에 wardId
- `?wardId=`가 보호자 브라우저 기록에 남는다. 다른 보호자 화면은 선택한 피보호자 저장소를 쓴다. 내용은 BE 인가가 막고 주소만으로는 아무것도 안 보이므로 **수용 권장**(새로 고침·공유 링크에서도 열리는 이점).

### 참고 (#253 이전부터)
- 이어 하는 대화(`resumed`)도 턴 수를 0에서 센다(`startTalk`) - "8번 중 1번째"와 진행 점이 실제보다 앞이다. 서버가 이어 하는 대화의 턴 수를 주지 않아 FE만으로는 못 고친다.
