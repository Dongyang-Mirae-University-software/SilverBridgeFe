# AI 의료 챗봇 보호자·피보호자 Claude 디자인 반영 (2026-10-30)

## 시안

- Claude Design 프로젝트 `70278963-88a1-44fa-8f33-f9952668d983`의 `SilverBridge-app.html` 중 `WardChatbot` 함수(2486-2650줄). 이 함수 하나가 `guardian` 값에 따라 두 화면을 그린다
  - 보호자: 헤더 + 대화 + "눌러서 물어보세요" 칩 + 입력창(1열)
  - 피보호자: 대화 카드 + 오른쪽 큰 빠른 질문 버튼 4개(2열, 챗봇 헤더 없음)
- 두 화면은 **일부러 다르게 보인다**(2026-10-30 사용자 확인). 이번에도 `ChatbotContent` 하나에 `variant="ward"` 분기를 유지했고, 두 화면을 합치지 않았다
- 이전 피보호자 화면(028d339, v13)은 지금 시안의 보호자 쪽 구조와 같았다. 시안이 바뀌어 피보호자 화면 구조를 새로 짰다

## 변경 파일

- `src/components/chatbot/ChatbotContent.tsx` - 역할별로 화면을 따로 반환(대화 목록·입력창 JSX는 공용 조각), 칩·빠른 질문 목록 분리, 인사말, 접기 상태 제거
- `ChatbotContent.module.css` - 보호자 = 기본 규칙(칩·입력창·보내기 크기), 피보호자 = `.wardVariant`·`.ward*` 전용 규칙(2열·1024px·760px 구간). 안 쓰게 된 초록 점·접기 토글·화살표 아이콘 규칙 삭제
- `ChatBubble.tsx` - 시각 표시 제거(두 역할), 피보호자 아바타 제거(`WardChatAvatar` 삭제)
- `ChatBubble.module.css` - 보호자 21px·모서리, 피보호자 `.wardBubble` 26px·행 폭 86%, 760px 이하 말풍선 최대 폭 `calc(100vw - 84px)`
  - 이전 폭(`100vw - 192px`)은 시각 표시 자리를 포함해 375px에서 183px이었고, 병원 검색 카드가 세로로 찌그러졌다. 시각을 빼면서 함께 고쳤다
- `ChatbotContent.browser.test.tsx`(신규) - 역할별 화면 차이, 대리 상담 context(`wardId`), 같은 `sessionId` 유지, history 미전송, 오류 후 재시도
- 손대지 않음: `ChatToolCard`·`ChatUiPrompt`·`ChatContextForm`(+ css), 두 `page.tsx`, `WardLayout`

## 공용 스타일 영향

- 보호자 쪽은 기본 규칙만 바꿨다. 피보호자 쪽은 해당 속성을 모두 `.wardVariant`/`.wardBubble`로 덮어쓰거나 별도 클래스를 써서 영향이 없다
- 피보호자 쪽 변경은 전부 `.wardVariant`/`.ward*`/`.wardBubble` 아래에 있어 보호자 화면에 영향이 없다

## 바뀌지 않는 것

- 보호자: 피보호자 선택, 대리 상담 context(`wardId`·`patientId` 등, BE가 연결 여부로 검증), 피보호자를 바꾸면 새 `sessionId`, 상담 기록 창
- 피보호자: 본인 상담 context `{ role }`만 보냄, 빠른 질문 바로 전송
- history 미전송(`chatRequestNoHistory.test.ts`), 대화창마다 같은 `sessionId`
- 예약 도구 카드·UI 선택지, 로딩 점(`role="status"`), 오류 문구, AI 기본 응답 배너
- 상담 내용은 콘솔·로그에 남기지 않는다(추가한 로그 없음)
