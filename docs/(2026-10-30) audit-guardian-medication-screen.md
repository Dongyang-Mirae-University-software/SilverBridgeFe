## 실서버 확인

- gosky dev BE에서 시험 보호자 계정 로그인이 **401**로 실패했다(15:2x, 1회). 잠금 위험 때문에 다시 시도하지 않았고, 아무 데이터도 바꾸지 않았다.
- 그래서 실계정 OCR·일괄 등록·반 알·여러 개 삭제와 알림 시각 변경은 **확인하지 못했다.** 화면이 쓰는 API 호출은 #166에서 바뀌지 않았다.
- 배포 상태: gosky dev·prod 모두 `/guardian/medication` 200, prod 빌드에 새 화면 코드가 들어 있다(PR #166 기록).

## 테스트 커버리지
