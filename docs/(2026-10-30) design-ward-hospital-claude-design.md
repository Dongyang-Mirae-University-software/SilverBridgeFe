# 피보호자 병원 가는 날 Claude 디자인 반영 (2026-10-30)

## 시안

- Claude Design 프로젝트 `70278963-88a1-44fa-8f33-f9952668d983`의 `SilverBridge-app.html`에서 `WardHospital` 함수 부분(2732-2785줄, 목 데이터 2개)
- 범위는 피보호자 "병원 가는 날" 화면 하나. 보호자 병원 예약(`GuardianHospital`)과 헤더 제목은 손대지 않았다

## 디자인 대조

| 디자인 요소 | 이전 구현 | 데이터 | 반영 |
|---|---|---|---|
| 다음 진료 큰 카드 2단: 왼쪽 브랜드색 칸 "병원 가는 날" + D-day(84px) | 한 단 카드 + 작은 알약 모양 D-day(20px) | `daysBetween(today, reservationDate)` | 반영. 768px 이하는 위아래로 쌓고 D-day는 64px |
| D-day 문구 "오늘 / 내일 / N일 뒤" | "오늘이에요 / N일 남았어요" | 같음 | 반영 (Q1) |
| 달력 아이콘 + 날짜·시각(38px) | 아이콘 없음, 34px | `reservationDate`·`reservationTime` | 반영 (`Icon` `calendar`) |
| 청진기 아이콘 + 병원명(36px)·주소(23px) | 아이콘 없음, 24px·18px | `hospitalName`, 주소는 병원 목록 `IHospital.address`에서 이름으로 찾음 | 반영. 청진기 아이콘이 없어 기존 `hospital` 아이콘 사용 |
| 진료과 | 디자인에 없음 | `department` | 유지 (Q2 - 같은 병원의 다른 과를 구분하려고) |
| 나머지 예약: 예약마다 카드 한 장("그다음" + D-day \| 날짜·시각 + 병원) | "그 밖의 예약" 목록 카드 하나 | 같음 | 반영. 영역 이름 `aria-label="그 밖의 예약"`은 유지 |
| 빈 상태 "병원 갈 날이 없어요"(28px) | "다음 진료 / 예정된 진료가 없어요" | - | 반영 (Q3) |
| 지난 진료 + 페이지 나누기 | 있음 | 있음 | 디자인에는 없지만 유지 |
| 시연 안내·로딩·실패 시 다시 불러오기·"예약은 보호자가 대신 잡아 드려요" | 있음 | - | 디자인에는 없지만 유지 |

- 디자인에 있는데 API에 없는 값: 없음
- 디자인의 "그다음" 라벨(17px)은 이 화면의 최소 글자 크기에 맞춰 18px로 키웠다

## 바뀌지 않는 것

- 보기 전용(예약 생성·취소 없음, 버튼은 실패 시 다시 불러오기와 지난 진료 페이지 버튼뿐)
- KST(`useKstNow`) 기준 다가오는/지난 진료 구분, 지난 진료 5건씩 페이지 나누기, 취소된 예약은 "취소됨" 표시
- 시연용 가상 병원 안내(`ReservationDemoNotice`)
- 로딩·실패·빈 상태 문구(빈 상태 큰 문구만 디자인 문구로 바꿈), `role="alert"`, 영역 `aria-label`
- 증상(`symptomSummary`)은 화면에 싣지 않는다
- 병원 목록을 못 불러오면 주소 줄만 빠진다
